# Project Setup Guide  

## Folder Structure  
Project Folder  
|______ Client/   (Place all files except server.js here)  
|  
|______ Server/   (Contains server.js)  

## Running the Project  

### Client Side  
1. Open Command Prompt and navigate to the Client folder:  
   cd Client  
2. Install dependencies:  
   npm install  
3. Start the client:  
   npm run dev  

### Server Side  
1. Open another Command Prompt and navigate to the Server folder:  
   cd Server  
2. Start the server:  
   npm start  
   OR  
   node server.js
